# یار مهدوی

نسخهٔ اندروید برنامهٔ یار مهدوی.

## وضعیت نسخه 1.3.0
- حداقل نسخهٔ اندروید: 7.0 (API 24)
- حالت روشن و تاریک
- تنظیم جداگانهٔ اندازهٔ قلم عربی و فارسی
- انتخاب قلم از حافظهٔ دستگاه
- اسکرول خودکار متن دعا با کنترل سرعت
- تقویم هجری شمسی با تبدیل تاریخ و تعطیلات ثابت شمسی
- بخش‌های ادعیه، زندگی‌نامه و احادیث مهدوی

## محدودیت‌های شفاف
- متن کامل قرآن، نهج‌البلاغه و صحیفه سجادیه هنوز در بستهٔ آفلاین این نسخه قرار ندارد.
- تقویم، مناسبت‌های قمری و تعطیلات متغیر را نمایش نمی‌دهد.
- فایل صوتی دعا و قابلیت‌های آنلاین هنوز فعال نیستند.
- هیچ ادعایی دربارهٔ بی‌باگ بودن کامل برنامه یا آزمایش روی همهٔ گوشی‌ها وجود ندارد؛ پیش از انتشار عمومی باید روی چند نسخهٔ واقعی اندروید آزمون شود.

## حریم خصوصی
برنامه در این نسخه حساب کاربری یا سرویس آنلاین ندارد. قلم انتخابی و تنظیمات به‌صورت محلی نگهداری می‌شوند.
